FUNCTION

FUNCTION name(parameter, parameter, ...) {
    equations;
    name = expression;
}
... = name(argument, argument, ...) ...;

A FUNCTION is a piece of logic that is written once and used in several equations. A call is replaced by the expression assigned to the function's own name, with the arguments put in place of the parameters. An equation inside the function that assigns to a parameter assigns to the signal given as that argument; this is how a function returns more than one result.

/* Full adder; the carry is passed back through a parameter */
function add(a, b, c, carry) {
    carry = a & b # a & c # b & c;
    add = a $ b $ c;
}

sum = add(x, y, cin, cout);

The call above gives the two equations

cout = x & y # x & cin # y & cin;
sum  = x $ y $ cin;

The parameter names are local to the function: a, b and c above have nothing to do with pins of the same name. A function must be defined before it is called.

For text that should be repeated with different names (several statements, a whole state machine), use a $MACRO instead.

See also: Equations, Macros.
