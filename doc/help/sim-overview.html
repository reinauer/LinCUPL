Simulator overview

csim checks a compiled design against test vectors. Each vector sets the inputs, clocks the registers if asked to, and compares the outputs with the values the vector expects. The simulation works on the equations as they were compiled for the device, so it also catches mistakes in pin polarity, output enables and reset logic.

The steps

  1. Compile the design with -a to get the absolute file (.abs). LinCUPL's default options include it.
  2. Write the test vectors in a .si file with the same base name as the design (counter.pld, counter.si); see test vector files.
  3. Run csim. It prints every vector and writes the listing (.so) and the waveform file (.wo).
  4. Read the listing: each output that differs from the expected value is marked.
ORDER: clk, en, rst, pre, oe, %2, count, %2, carry;

VECTORS:
$MSG "Reset, then count from 0";
0 0 1 0 1  "0" L
C 1 0 0 1  "1" L
C 1 0 0 1  "2" L
C 0 0 0 1  "2" L
$REPEAT 12;
C 1 0 0 1  "*" *
$MSG "Count is 14 now; carry is high at 15";
C 1 0 0 1  "F" H
C 1 0 0 1  "0" L
$MSG "Preset on the next clock";
C 0 0 1 1  "F" L
$MSG "Outputs off";
0 0 0 0 0  "Z" L

The csim command

csim [-flags] [-u library] [device] name

name is the base name of the design: csim -l counter reads counter.abs and counter.si. A device (e.g. virtual) must be the one the design was compiled for.

FlagEffect
-lWrite the listing (.so) and the waveform file (.wo).
-wThe same; used by LinSim.
-jAdd the vectors to the JEDEC file, for device programmers that test the programmed part. A design with a pin without a number gets no vectors; csim names the first such pin in note [0033sa].
-nThe JEDEC file is named after the design file, as with cupl's -n.
-u libraryDevice library.

Without -l or -w the results go to the console only. csim ends with exit status 1 when a vector fails.

In LinCUPL and LinSim

  • Run > Device Dependent Simulate (F10) simulates the open design; Compile & Simulate (F11) compiles first. Device Independent Simulate (Shift+F10) uses the virtual device. The flags are set in Options > Simulator Options.
  • File > New Simulation (.SI) starts a .si file with the header and the pins of the open design.
  • LinSim (F12) shows the vectors as waveforms, edits them and runs csim.
