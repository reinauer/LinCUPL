Preprocessor

Before the design is compiled, the preprocessor replaces symbols, reads included files and leaves out conditional parts. Its commands start with $ in the first column of a line and may be written in any case.

CommandEffect
$DEFINE symbol [text]From here on, symbol is replaced by text.
$UNDEF symbolForget a symbol.
$INCLUDE fileRead another file at this place.
$IFDEF symbolKeep the following lines only if the symbol is defined.
$IFNDEF symbolKeep the following lines only if the symbol is not defined.
$ELSESwitch to the other branch.
$ENDIFEnd of the conditional part.

Example

$include pins.inc

$define ROTATE_LEFT                 /* remove this line to rotate right */
$define HOLD    !load & !shift      /* text substitution, not a signal */

Pin 11 = shift;

field data = [d7..0];
field reg  = [q7..0];

/* One equation per bit, made by $REPEAT; {i} is replaced by the
   value of i and {expression} by the value of the expression */
$REPEAT i = [0..7]
$ifdef ROTATE_LEFT
q{i}.d = load & d{i} # !load & shift & q{(i+7)%8} # HOLD & q{i};
$else
q{i}.d = load & d{i} # !load & shift & q{(i+1)%8} # HOLD & q{i};
$endif
$REPEND

reg.oe = oe;

with the included file

/* Pin assignments shared by several designs; read with $include */

Pin 1  = clk;
Pin 2  = load;
Pin [3..10] = [d7..0];
Pin 13 = !oe;
Pin [14..21] = [q7..0];

$DEFINE

The text of a $DEFINE runs to the end of the line; a comment at the end is not part of it. The text may be empty, which is useful for $IFDEF. It is inserted as written, so HOLD above becomes !load & !shift inside the larger expression; put parentheses into the text if the expression around it could bind differently. Defining a symbol that is already defined is an error (already defined); use $UNDEF first.

Symbols are commonly used for state encodings (traffic.pld) and for constants that occur in several places.

$INCLUDE

The file is looked for in the directory of the design, then in the directory of the device library and in its Macro subdirectory. The name is matched without regard to case. Included files may contain any statements, such as pin declarations or macro definitions.

Conditional parts

$IFDEF and $IFNDEF with $ELSE and $ENDIF select lines by whether a symbol is defined. They work inside $REPEAT as well. To choose by the value of an expression, use $IF.

The commands must start in the first column. An indented $ifdef is not seen by the preprocessor and gives a syntax error.

See also: Macros and $REPEAT, -e to see the expanded source.
