PROPERTY

PROPERTY vendor { name = value; name = value; ... };

A PROPERTY statement passes options to the fitter of a CPLD. cupl does not interpret them; it copies each name = value pair into the fitter input file (.tt2). For the ATF150x devices the vendor is atmel:

property atmel { preassign = keep };   /* use the pin numbers given below */

Several options may stand in one block, separated by semicolons, or in several PROPERTY statements:

property atmel { preassign = keep; output_fast = on; pin_keep = off };

Some options take a list of pin names instead of on or off and then apply to these pins only. The fitter page lists the options of the ATF150x fitters. For devices without a fitter the statement is accepted and has no effect.

A source line may be at most 255 characters long; spread long property lists over several lines.

See also: ATF150x fitters, Compiler options.
