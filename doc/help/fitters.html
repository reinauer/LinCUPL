ATF150x fitters

The ATF1502, ATF1504 and ATF1508 CPLDs have too many ways to route a signal for cupl to place a design itself. For these devices cupl compiles and minimizes the design, writes it as a fitter input file (.tt2) and runs the fitter of the family: fit1502, fit1504 or fit1508. The fitter assigns the signals to pins and macrocells, routes them and writes the JEDEC file.

cupl -jaxl cpld.pld        # runs fit1502 for Device f1502ispplcc44

The fitter's console output appears in the build log; its files are described under output files. When the fitter reports an error (a design that does not fit, an input it could not read) cupl adds [0010ck] Fitter could not fit design and ends with Error Code = 1 and exit status 1, so a make file or script stops there and LinCUPL reports the build as failed; the fitter's own messages in the build log or the .fit report say why. (The original CUPL ends with Error Code = 0 in that case.) The simulator works from the .abs file that cupl writes, as for any other device.

EDIF input

The fitters also accept EDIF 2 0 0 netlists directly, including Yosys generic gate netlists and hierarchical designs. Select -ifmt EDIF:

fit1502 -i design.edf -ifmt EDIF -device PLCC44 -tech ATF1502AS -pinfile board.pin

The optional pin file contains signal : pin assignments; bus members use names such as data[0]. Built-in primitives cover common gates, flip-flops, latches and tristate buffers. -lib cells.lib adds primitive definitions in the fitter's GATE/PGATE format. Unknown cells, unresolved connections and combinational loops are errors.

The EDIF path produces fitted equations and JEDEC files, without a CUPL absolute file. Functional simulation through csim still requires the compiled CUPL design; ATF150x fuse-map simulation is not available.

Example

Device   f1502ispplcc44;

/* An 8-bit counter with a compare register in an ATF1502AS (PLCC44,
   in-system programmable: the JTAG pins stay reserved).  cupl writes
   the fitter input (cpld.tt2) and runs fit1502, which places the logic
   and writes the JEDEC file. */

property atmel { preassign = keep };   /* use the pin numbers given below */

Pin 43 = clk;                          /* global clock input */
Pin 1  = rst;                          /* global clear input */
Pin 2  = load;                         /* load the compare register */
Pin [4,5,6,8,9,11,12,14] = [d0..7];
Pin [16..21,24,25] = [q0..7];
Pin 26 = match;

Pinnode = [r0..7];                     /* buried registers; the fitter
                                          chooses their macrocells */
Node    count_is_zero;                 /* a buried combinational node */

field count   = [q7..0];
field compare = [r7..0];
field data    = [d7..0];

/* Counter: bit i toggles when all lower bits are 1 */
q0.t = 'b'1;
$repeat i = [1..7]
q{i}.t = [q{i-1}..0]:&;
$repend
count.ck = clk;
count.ar = rst;

/* Compare register: loads the data inputs */
compare.d  = data & load # compare & !load;
compare.ck = clk;
compare.ar = rst;

count_is_zero = count:0;
match = (count == compare) & !count_is_zero;

In the 44-pin ATF1502, pins 3, 15, 23 and 35 are VCC and pins 10, 22, 30 and 42 are ground; pin 43 is the global clock and pin 1 the global clear input. The isp devices keep pins 7, 13, 32 and 38 for the JTAG port (TDI, TMS, TCK, TDO).

Pin assignment

Pins may be given numbers in the design, or left to the fitter (Pin = name;). The preassign property says what the fitter does with given numbers. The pins it chose are in the .pin and .fit files, and Utilities > Assign Pins and Pinnodes writes them back into the design (see backpin), so the next fit keeps them and the board layout stays valid.

Fitter options

Fitter options are set in the design with a PROPERTY statement; cupl passes them to the fitter in the .tt2 file:

property atmel { preassign = keep; output_fast = on };
PropertyValues (default first)Effect
preassignkeep, try, ignoreUse the pin numbers of the design: always, if possible, or not at all.
pin_keepon, offBus-hold circuit on the I/O pins, which keeps an undriven pin at its last level.
output_fastoff, on, pin namesFast output slew rate (default slow).
open_collectoroff, on, pin namesOpen-drain outputs.
securityoff, onProgram the security fuse.
jtagby deviceKeep the JTAG port. cupl tells the fitter on its command line: -JTAG ON for the isp devices, -JTAG OFF for the others. The property can only switch the port off: jtag = off frees the four pins of an isp device for logic, but jtag = on on a device without isp in its name is overridden by -JTAG OFF. To keep the port, choose the isp device.
tdi_pullup, tms_pullupoff, onInternal pull-ups on the JTAG inputs.
power_resetoff, onPower-on reset of the registers.
mc_poweroff, on, pin namesReduced-power mode of the macrocells.
optimizeon, offLogic optimization in the fitter.
xor_synthesisoff, onUse the macrocells' XOR gates for XOR logic.
foldback_logicon, offUse foldback product terms.
cascade_logicoff, onCascade product terms from neighbouring macrocells.
soft_buffer, logic_doubling, push_gate, global_fold, global_oe, gck_itd, fast_inlatch, twoclockFurther placement and synthesis controls; see fit1502 -h2.

The .fit report lists the options in effect at its top. A name the fitter does not know is reported there (PROPERTY ... is invalid and ignored) and has no effect.

Running a fitter by hand

fit1502 -i cpld.tt2 -CUPL -dev P1502C44 -JTAG ON
fit1502 -h2                     # list of all -strategy options

Options of the form -strategy name value correspond to the properties above. The device names are P1502C44 and P1502T44 (PLCC and TQFP) for the ATF1502, and similar names for the ATF1504 and ATF1508; fit1504 and fit1508 print theirs when started without arguments.

Where the fitters are found

cupl looks for the fitter next to itself and on the PATH. A fitter that exists only as a Windows program (.exe) is looked for in the directory named by LINCUPL_FITTERS, in the current directory and in a Fitters directory beside the device library, and is run with Wine (LINCUPL_WINE names the Wine command, else wine is taken from the PATH).

See also: PROPERTY, backpin, fitter output files.
