Devices and libraries

cupl knows a device by its mnemonic, the name written in the Device line of the design. The mnemonics, pin counts, fuse maps and the extensions of each device are kept in a device library (.dl file).

Device names

MnemonicDevice
g16v8, g16v8a, g16v8ma, g16v8ms, ...GAL16V8 / ATF16V8 (20 pins); the suffixes select an operating mode or device variant
g20v8, g20v8a, ...GAL20V8 / ATF20V8 (24 pins)
g22v10, p22v10GAL22V10 / ATF22V10, PAL22V10 (24 pins)
v750c, v750cext, ...ATF750C (24 pins, buried registers)
v2500c, ...ATF2500C (40 pins)
f1502plcc44, f1504plcc84, f1508qfp100, ...ATF1502/1504/1508 CPLDs: family, package and pin count; placed by a fitter
f1502ispplcc44, ...the same CPLDs with the JTAG port kept for in-system programming
...lcc (e.g. g22v10lcc)the 28-pin PLCC package of a device
virtualthe virtual device

Pin numbers in a design are the pins of the package the mnemonic names: g22v10 and g22v10lcc have different numbers for the same signals.

Device libraries

LibraryContents
Atmel.dlThe Atmel devices: ATF16V8, 20V8, 22V10, 750, 2500 and the ATF150x CPLDs, plus virtual.
cupl.dlSeveral hundred PAL, GAL, PROM and other devices of many makers.
lincupl.dlBoth of them in one library: the devices of Atmel.dl, then those that only cupl.dl has. It is made from the two when LinCUPL is built, with cbld.

Atmel.dl and cupl.dl stay as they came with WinCUPL. A device that is in both comes from Atmel.dl in lincupl.dl, and a design for it gives the same files as with -u Atmel.dl. A device of cupl.dl gives the same .jed as with -u cupl.dl; only the .abs file, which records where the device is in the library, differs.

The library is chosen in this order:

  1. the -u option of cupl, csim, cbld or backpin;
  2. the LIBCUPL environment variable (a .dl file or a directory);
  3. the LINCUPL_SHARE environment variable (a directory);
  4. the share/lincupl directory next to the programs, then the installed one. In a directory, lincupl.dl is preferred, then Atmel.dl, then cupl.dl.

The original programs come with Atmel.dl as the library: a device of cupl.dl needs -u cupl.dl there. With LinCUPL it can be used without -u.

LinCUPL passes the library chosen in Options > Environment & Tool Paths with -u; the status bar shows it.

Choosing a device in LinCUPL

Options > Devices lists the devices of the library with their pins, product terms and fuses. The list can be filtered by package and by name, and Inspect with cbld shows the details and extensions of the selected device. The chosen device is written into the Device line of the design, or set as a device override that is passed to cupl instead of the design's device (and kept with the project).

Looking into a library

cbld -tu Atmel.dl              # all device names
cbld -lu Atmel.dl g22v10       # pins, fuses and product terms
cbld -eu Atmel.dl g22v10       # extensions

See cbld. Utilities > Device Library Table of Contents shows the first list.
