Simulator directives

Directives stand between the vectors of a .si file. They start with $ and end with a semicolon, or with a colon where a block of vectors follows.

DirectiveEffect
$MSG "text";Print a message.
$REPEAT n;Run the next vector n times.
$FOR i = a..b : ... $ENDF;Run the vectors of the block once per value.
$DO : ... $UNTIL cond;Run the block, then again until the condition holds.
$WHILE cond : ... $ENDW;Run the block as long as the condition holds.
$IF cond : ... $ELSE : ... $ENDIF;Run one of two blocks.
$SIMOFF; ... $SIMON;List vectors without simulating them.
$EXIT "text";End the simulation.
$TRACE n;Show internal values while simulating.
VAR, $SET, $COMP, $OUTCompute test vectors from variables.

The examples on this page come from stepper.si, which tests a 3-bit counter with enable (en), synchronous clear (clr) and an output top that is high at 7:

ORDER: clk, en, clr, %3, cnt, %2, top;

VECTORS:
$MSG "Clear the counter";
C 0 1  "0" L

$MSG

Prints the text when the simulation reaches it, on the console and in the listing, between the vectors. Messages make the listing easier to follow and appear as comments in LinSim.

$REPEAT

Runs the vector that follows n times. With * as the expected values the listing shows what the design did:

$MSG "Hold the count for four clocks";
$REPEAT 4;
C 0 0  "3" L

$FOR

Runs the vectors up to $ENDF once for each value from a to b:

$MSG "Count to 5 with a loop";
$FOR i = 1..5 :
C 1 0  "*" *
$ENDF;

Conditions

$UNTIL, $WHILE and $IF test the simulated state: a signal compared with H or L, or a field compared with a value in single quotes. The operators are = (equal), # (not equal), < and >.

$DO ... $UNTIL

Runs the block, then tests the condition and repeats the block until it is true:

$MSG "Count until the top output is high";
$DO :
C 1 0  "*" *
$UNTIL top = H;

$WHILE

Tests the condition first and runs the block while it is true:

$MSG "Wrap around while the count is not 3";
$WHILE cnt # '3' :
C 1 0  "*" *
$ENDW;

A loop whose condition never changes does not end; make sure the vectors in it change the state that the condition tests.

$IF

$IF cnt = '3' :
C 0 0  "3" L
$ELSE :
C 0 1  "0" L
$ENDIF;

A $MSG or $EXIT inside a branch counts only when its branch runs, also in nested $IFs and inside $FOR and $WHILE loops.

The original csim prints a message inside a branch whichever branch runs, and an $EXIT in a branch that does not run still ends the simulation. Put $MSG before the $IF in test files that are also run with it.

$SIMOFF and $SIMON

Vectors between $SIMOFF and $SIMON are copied into the listing as written but not simulated; the state of the design does not change. This keeps vectors for later without deleting them.

$MSG "Not simulated:";
$SIMOFF;
C 1 0  "7" H
$SIMON;

$EXIT

Ends the simulation with a message; the vectors after it are not run.

$EXIT "End of the test";
C 1 0  "*" *

$TRACE

$TRACE 0; to $TRACE 4; set how much csim prints about each vector: 0 (the default) nothing extra; higher levels print the signal values before, at and after the clock and the register contents (REGS), and level 3 also every equation as it is evaluated. The trace goes to the console, i.e. into LinCUPL's build log.

Variables: VAR, $SET, $COMP and $OUT

Instead of writing every vector, a test can keep values in variables, compute with them and output a vector made from them:

ORDER: clk, en, clr, %3, cnt, %2, top;
VAR ctl = en, clr;          /* after ORDER, before VECTORS; no $ */
VAR n = en, clr;

VECTORS:
C 0 1 "0" L
$SET ctl = 10;              /* one test value per signal: en=1, clr=0 */
$SET cnt = ***;             /* expect nothing particular */
$SET top = *;
$OUT;                       /* run the vector made of the current values */
$SET n = '1';               /* a number in single quotes */
$COMP n = n + 1;            /* n is now 2: en=1, clr=0 */
$OUT;
  • VAR name = signals; stands between ORDER and VECTORS and is written without $; anywhere else it is an error (misplaced variable declaration, or invalid syntax for $VAR). Every signal and field of the ORDER statement is a variable as well.
  • $SET variable = values; gives one test value (0 1 H L X C K P Z N R *) per signal, or 'number' in the current BASE. An unquoted number of the wrong width is bad width for constant.
  • $COMP variable = expression; computes with + - * /, & (and), # (or), $ (exclusive or), ! and parentheses. The operators bind in this order, tightest first: !, &, # $, * /, + -; so 1 # 2 + 1 is 4. Use parentheses when in doubt. The variables used must hold 0 or 1 in every bit.
  • $OUT; simulates one vector made of the current values of all signals: inputs as last set, expected outputs as in the vector before unless they were set with $SET. Set them to * to list what the design does.

The keywords $MACRO, $MEND and $CALL are recognised but do not give working test files; repeat vectors with $FOR or $REPEAT instead. Since keywords are recognised everywhere, signals cannot be called set, out, var or comp.
