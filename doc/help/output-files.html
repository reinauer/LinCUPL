Output files

The files are written next to the design and named after it (counter.pld gives counter.lst, counter.doc, ...). The JEDEC file is the exception: it is named after the Name line of the header (Name Counter; gives Counter.jed) unless the -n option is given. Without any output option cupl only checks the design.

Files written by cupl

FileOptionContents
.jed-jJEDEC fuse map for the device programmer: the fuse states, the fuse checksum and, after csim -j, the test vectors. -g also sets the security fuse (G1). For an ATF150x the fitter writes it.
.lst-lListing: the source with line numbers and every error and warning under the line it belongs to.
.doc-xDocumentation: the expanded and minimized product terms of every output, the symbol table (pins, nodes, extensions, product terms used and available) and, for fixed-architecture devices, the fuse plot with -f.
.abs-aAbsolute file: the compiled design in binary form, read by the simulator. Needed before simulating. Its tab shows it decoded: the header, the symbol table, the product terms of every OR array as rows of 1, 0 and - with the equation csim makes of them (including whether the output complements them), and the field lists. The Raw button in the tab shows the bytes as hex.
.sim-aReadable form of what the simulator uses: pins, fields and the final equations.
.pla-bBerkeley PLA format: the product terms as a table of inputs and outputs, for other logic tools.
.mx-eThe design after macro expansion ($MACRO, $REPEAT, $INCLUDE): useful to see what the macros produced.
.pds-cPALASM source of the design.
.pdf-pPDIF netlist (a text netlist format, not a PDF document).
.edf-tEDIF netlist.
.hex, .hl-h, -iASCII-hex and HL download formats, for the devices that use them (PROMs and some PLDs); other devices get a warning.
.tt2(fitter devices)Fitter input in PLA form with the pin assignments and PROPERTY options; cupl writes it for devices that are placed by a fitter and then runs the fitter.

Files written by the ATF150x fitters

FileContents
.fitFitter report: the options in effect, the pin and node placement, the resources used and the equations as placed.
.pinThe pin and node numbers the fitter chose, one line per signal.
.ioThe same assignment as a CHIP block with the type of each signal (input pin, output pin, node).
.tt3The equations after fitting, in PLA form.
.jedThe JEDEC file of the device.

The pin numbers chosen by the fitter can be written back into the design with backpin.

Files written by csim

FileOptionContents
.so-l or -wSimulation listing: the .si file with line numbers, then every vector with the simulated values and a message for each output that differs from the expected value. See reading the listing.
.wo-l or -wWaveform file: the header, fields, ORDER and the simulated vectors in a form that LinSim reads.
.jed-jThe test vectors are added to the JEDEC file (V fields) and its checksum is updated.

Without -l or -w the simulator prints the vectors and messages and writes no file. With -f csim reads the fuse map of the .jed file instead of the .abs file (simulating a JEDEC file).

Other files

cupl works with temporary files in the design's directory and removes them when it ends. backpin keeps a copy of the design it changes (.bak).

See also: Compiler options, Simulator.
