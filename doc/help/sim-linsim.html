LinSim

LinSim shows the test vectors of a .si file as waveforms, lets you draw and change them, and runs the simulator. Start it from LinCUPL with Run > Launch Waveform Simulator (F12), which opens the vectors of the current design, or on its own with a .si or .wo file.

The window

Each document has a window of its own with three tabs, also reached through the Window menu:

  • Waveform Editor (Alt+1): one row per signal, one column per vector. Buses (fields) can be expanded into their bits.
  • Simulation Listing (.SO) (Alt+2): the listing of the last run.
  • Simulation Source (.SI) (Alt+3): the text of the .si file. Edits here are taken over into the waveforms.

The simulation console below the tabs shows the commands LinSim runs and their output, with the messages in a list of their own. View > Signal Definitions shows the declaration of the selected signal. File > New Window opens an empty window; the Window menu lists all open windows and can cascade or tile them, and Open LinCUPL IDE opens the design in LinCUPL.

Editing vectors

  • Click a cell or drag over a range of signals and vectors, then type a state: 0 1 for inputs, C K P for clocks, L H Z X * for outputs (see the table of values). Signal > Set Selection State does the same from the menu.
  • Ctrl+click sets * (value left to the simulator).
  • A double-click toggles a single signal or opens Set Bus Value (Ctrl+B) for a bus.
  • Shift+click on the ruler sets a reference marker for measuring.
  • Edit > Cut / Copy / Paste Vectors and Undo / Redo work on whole vectors.

The Signal menu adds signals and buses (Ctrl+Shift+S), renames, deletes and moves them (Alt+Up, Alt+Down), expands or collapses buses, adds vectors (Ctrl+I), duplicates the current one (Ctrl+D), deletes the selected vectors and edits the message of a vector, which is saved as a $MSG. File > Design Properties edits the header and the base of the file.

Find

Edit > Find (Ctrl+F) searches the tab that is shown. In the waveform editor it finds a signal by name, a vector by its number, or a vector by the text of its comment or $MSG; in the listing and source tabs it searches the text. Find Next (F3) and Find Previous (Shift+F3) repeat the search, also while the Find box has the focus.

Simulating

Simulator > Simulate (F9) saves the .si file if it was changed and runs csim -lw on it. If the design has no absolute file yet, or with Compile & Simulate (Shift+F9), it first compiles the .pld of the same name with cupl -ja -m1. The simulated outputs are then merged into the waveforms and the listing tab is updated.

  • Assign Simulator Results makes the simulated output values the expected values of the vectors, so a run that has been checked by eye becomes a regression test.
  • Append Vectors to JEDEC adds -j, Use PLD Filename for JEDEC adds -n (see csim).
  • Set Library chooses the device library.

Saving, printing and export

File > Save (.SI) writes the vectors as a .si file; a document opened from a .wo file is saved as the .si of the same name. Save All (Ctrl+Alt+S) saves every open window. Export Waveform PNG / PDF and Print write the waveforms; Print Colors chooses between the screen colours and black and white. The View menu sets zoom, row height, the grid and its size, wide signal rows and the colours.

Help > Waveform States & Shortcuts shows a summary of the states and mouse actions.
