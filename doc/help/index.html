LinCUPL Help

LinCUPL is an editor and front end for cupl, a compiler for programmable logic devices (PAL, GAL, ATF22V10, ATF750, ATF2500, ATF150x and many others), and for csim, its logic simulator. You describe a design in the CUPL language in a .pld file; cupl turns it into a JEDEC fuse file for a device programmer. Test vectors in a .si file check the design in csim. LinSim shows and edits the test vectors as waveforms.

Where to start

  • Getting started: the LinCUPL window, a first design, compiling and simulating.
  • Output files: what the compiler and the simulator write.
  • The CUPL language: the parts of a design file.
  • The simulator: test vectors, csim and LinSim.
  • Devices and libraries: device names and the device libraries.

Using this help

The Contents and Index tabs beside the page find topics, and the Search tab searches the text of all pages (when LinCUPL was built with the Qt Help module); Find in Page (Ctrl+F) searches the page shown. In the LinCUPL editor, F1 on a CUPL keyword, a pin extension or a simulator directive opens its description; elsewhere F1 opens this page.

Every example design on these pages is in the doc/help/examples directory of the LinCUPL sources, and the test suite compiles and simulates each of them.
