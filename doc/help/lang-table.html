TABLE

TABLE inputs => outputs {
    value => value;
    ...
}

A TABLE describes logic as a truth table. inputs and outputs are fields, lists or single signals. Each entry maps a value of the inputs to a value of the outputs; the outputs are 0 for every input value the table does not list. Values are hexadecimal unless they have a base prefix.

Pin [2..5]   = [d3..0];
Pin [12..18] = ![sa, sb, sc, sd, se, sf, sg];

field digit    = [d3..0];
field segments = [sa, sb, sc, sd, se, sf, sg];

table digit => segments {
    'h'0 => 'b'1111110;   'h'1 => 'b'0110000;
    'h'2 => 'b'1101101;   'h'3 => 'b'1111001;
    'h'4 => 'b'0110011;   'h'5 => 'b'1011011;
    'h'6 => 'b'1011111;   'h'7 => 'b'1110000;
    'h'8 => 'b'1111111;   'h'9 => 'b'1111011;
    'h'A => 'b'1110111;   'h'B => 'b'0011111;
    'h'C => 'b'1001110;   'h'D => 'b'0111101;
    'h'E => 'b'1001111;   'h'F => 'b'1000111;
}

The segment outputs are declared active low, so the table is written with 1 for a lit segment and cupl inverts the pins.

Ranges and don't-cares

An input value may be a range or contain X digits; the entry then applies to every matching input value:

table inp => res {
    [0..7] => 1;
    [8..B] => 2;
    [C..F] => 3;
}
table inp => res { 'b'1XXX => 3;  'b'0XXX => 1; }

Each output bit becomes an OR of the input values for which it is 1, and is then minimized. A table with a single output signal (table inp => y0 { 0 => 1; 5 => 1; }) is a convenient way to write a list of minterms.

OUT is a reserved word, so a field cannot be called out.

See also: CONDITION, State machines.
