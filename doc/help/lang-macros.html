Macros and $REPEAT

The macro language generates design text: it repeats lines with a loop variable, computes numbers, and expands named macros with parameters. The result can be seen in the .mx file (-e).

$REPEAT

$REPEAT variable = [list]
lines
$REPEND

The lines between $REPEAT and $REPEND are written once for every value in the list, with {variable} replaced by the value. The list holds numbers and ranges separated by commas: [0..7], [7..0] (counting down), [0, 2, 4..6]. Loops may be nested two deep.

/* Counter: bit i toggles when all lower bits are 1 */
q0.t = 'b'1;
$repeat i = [1..7]
q{i}.t = [q{i-1}..0]:&;
$repend

expands to q1.t = [q0..0]:&;, q2.t = [q1..0]:&; and so on up to q7.t.

Expressions in braces

Braces hold an integer expression whose value replaces them:

OperatorsMeaning
+ - * / %arithmetic on integers (/ truncates, % is the remainder)
**power
== != < > <= >=comparison, 1 or 0
log2( ), log8( ), log10( ), log16( )number of digits needed for a value: log2(16) is 4, log2(9) is 4
( )grouping

Inside the braces a loop variable is written without braces: q{(i+7)%8}. The value is written in decimal, or in the base of a prefix just before the braces: f:'h'{i+10} gives f:'h'a for i = 0. An expression may start with a function: {log2(16)} gives 4, inside $REPEAT as well as outside.

Inside $REPEAT the original CUPL does not compute an expression that starts with a function name: the braces stay in the text and its preprocessor stops with unexpected end-of-file. Write {(log2(16))} in designs that are also compiled with it.

$REPEAT i = [0..7]
$ifdef ROTATE_LEFT
q{i}.d = load & d{i} # !load & shift & q{(i+7)%8} # HOLD & q{i};
$else
q{i}.d = load & d{i} # !load & shift & q{(i+1)%8} # HOLD & q{i};
$endif
$REPEND

$IF

$IF(expression)
lines
$ELSE
lines
$IFEND

Keeps the first group of lines when the expression is not 0 and the second otherwise; $ELSE is optional. Inside a loop:

$REPEAT i = [0..7]
$IF(i < 4)
y{i} = a{i};
$ELSE
y{i} = !a{i};
$IFEND
$REPEND

$MACRO

$MACRO name parameter parameter ...
lines
$MEND

name(argument, argument, ...);

A macro is a named piece of text with parameters, separated by blanks in the definition. A call, written like a function call with a semicolon, inserts the text with every parameter replaced by its argument. The number of arguments must match (incorrect number of parameters for Macro call), and the macro must be defined before it is called. Since the replacement is plain text, a parameter may even stand for a keyword:

$MACRO counter kind name
kind name {
    present 0  if up next 1;  default next 3;
    present 1  if up next 2;  default next 0;
    present 2  if up next 3;  default next 1;
    present 3  if up next 0;  default next 2;
}
$MEND

counter(sequenced,  dcount);
counter(sequencejk, jcount);
counter(sequencers, rcount);
counter(sequencet,  tcount);

Macro libraries

Macros used in several designs can be kept in a file of their own and read with $INCLUDE. The Macro directory beside the device library is searched for such files. In LinCUPL, Edit > CUPL Macros helps to define a macro, to add one to a library file and to insert a call with the matching $include.
