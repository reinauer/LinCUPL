CONDITION

CONDITION {
    IF expression OUT outputs;
    ...
    DEFAULT OUT outputs;
}

A CONDITION block lists conditions and the outputs each one turns on. It is the combinational counterpart of a state machine without states: every output named after an IF becomes true when that expression is true, and the outputs after DEFAULT become true when none of the conditions is. An output named by several conditions is the OR of them.

field sel = [sel1..0];

/* 2-to-4 decoder: one line per selector value while enabled */
condition {
    if en & sel:0 out line0;
    if en & sel:1 out line1;
    if en & sel:2 out line2;
    if en & sel:3 out line3;
    default out none;
}

This is the same as the equations

line0 = en & sel:0;     line1 = en & sel:1;
line2 = en & sel:2;     line3 = en & sel:3;
none  = !(en & sel:0 # en & sel:1 # en & sel:2 # en & sel:3);   /* = !en */

The outputs are combinational; to register them, name the register input (out q.d) on a device that has one.
