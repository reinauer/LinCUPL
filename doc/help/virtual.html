Device independent design

The device virtual is not a real chip. It has as many inputs, outputs and nodes as a design needs, every kind of flip-flop and every pin extension, and no limit on product terms. Compiling for it checks the logic and lets the simulator test it before a device is chosen, or when the real device does not fit yet.

Compiling and simulating

A design can name the virtual device in its header (Device virtual;), or any design can be compiled for it by giving virtual as the device on the command line:

cupl -axl virtual gates.pld
csim -l virtual gates

In LinCUPL, Run > Device Independent Compile (virtual) (Shift+F9) and Run > Device Independent Simulate (virtual) (Shift+F10) do this for the open design. The same .si file serves both the virtual and the real device.

csim takes the test file with or without its extension: csim -l virtual gates and csim -l virtual gates.si both simulate gates.si against gates.abs. (The original csim looks for gates.si.abs for the virtual device and stops with could not open.)

A preload (P in the clock column, see Preload) loads the complement of the given values into the registers of active-high outputs of the virtual device: P 0 0 '5' X leaves the count at 2 (010 instead of 101). Outputs declared active low (Pin = ![q0..2];) are loaded with the values as given. For active-high outputs give the complement in the preload vector, or reach the state with clocked vectors.

No JEDEC file is written for the virtual device. The absolute file, the listing and the documentation file are, and the documentation shows the equations before any device-specific fitting.

Pins without numbers

A design for the virtual device may leave out the pin numbers. Each Pin = name; statement stands on a line of its own. NODE declares buried signals:

Device   virtual;

/* The same two-bit up/down counter for each kind of flip-flop.
   The virtual device has every kind, so this compiles device
   independently (cupl -a, or Device Independent Compile). */

Pin = clk;
Pin = up;
Pin = [d1..0];          /* D flip-flops */
Pin = [j1..0];          /* JK flip-flops */
Pin = [r1..0];          /* SR flip-flops */
Pin = [t1..0];          /* T flip-flops */

field dcount = [d1..0];
field jcount = [j1..0];
field rcount = [r1..0];
field tcount = [t1..0];

The virtual device has no clock pin: give every register a .ck equation. A register without one compiles, but never changes in the simulator. Before moving the design to a device, add the pin numbers and remove the extensions that device does not have.

XOR gates

With -kx XOR equations stay XOR in the virtual device, which shows the logic in its original form. See DeMorgan and polarity.
